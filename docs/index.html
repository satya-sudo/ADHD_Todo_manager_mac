Why it feels lighter

Built for momentum, not overhead.

Quick capture

Add a task from the menu bar without switching into a full app or building a whole list first.

Single active task

Focusbar keeps one task active at a time so your next step stays obvious.

Gentle reminders

Reminders stay quiet while you are focused and only nudge when there is something pending to come back to.

Tray-safe UI

Task names and reminder labels are trimmed specifically for the menu bar, so they stay stable across displays.

Local-first

Your tasks stay on your Mac in Application Support. No account, sync, or online dependency required.

Native packaging

The app is bundled and signed like a real macOS menu bar app, with native notification delivery.

Install

Build it, bundle it, run it.

Alpha

Focusbar is already usable, but it is still actively evolving. Expect quick improvements, a few rough edges, and occasional behavior changes as the focus flow, reminders, and packaging get refined.

Fast local run

./scripts/run-app-bundle.sh

This builds the icon, bundles the app, ad-hoc signs it, and launches Focusbar.app.

Install to Applications

./scripts/install-app.sh

Installs the bundled app into your Applications folder so you can launch it like a normal macOS app.

Create a release zip

./scripts/package-release.sh

Builds a distributable zip you can attach to GitHub releases or share directly.

Create a DMG installer

./scripts/package-dmg.sh

Builds a drag-and-drop macOS DMG installer with Focusbar.app and an Applications shortcut.

Download from GitHub

Releases → latest

Download the latest packaged zip or DMG from GitHub Releases.
